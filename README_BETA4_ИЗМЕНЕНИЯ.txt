Donathon Timer 0.9.4 Beta 4
==========================

ЗАЧЕМ: исправление распознавания речи и улучшение интерфейса.

1. Сделай резервную копию C:\Users\<пользователь>\AppData\Local\DonathonTimer\donathon.db.
2. Закрой установленный Donathon Timer.
3. Из скачанного архива Beta 4 Update скопируй ФАЙЛЫ и ПАПКИ в локальную папку DonathonTimer-GitHub (перезаписывая совпадающие). Не трогай .git и пользовательские данные.
4. В GitHub Desktop нажми Commit to main, затем Push origin.
5. На GitHub → Actions → Build and publish Windows beta → Run workflow, тег v0.9.4-beta4.
6. После зелёного результата найди Setup.exe в Releases, установи его поверх Beta 3.

ПРОВЕРКА РЕЧИ БЕЗ СТРИМА:
1. Открой Анализ и проверь, что компонент речи установлен.
2. Выбери микрофон, включи «Сохранять голос» ДО запуска новой сессии.
3. Запусти сессию на Главной, говори 30–60 секунд, заверши сессию.
4. Выбери сессию рядом с «Распознать речь», посмотри строку о найденной аудиозаписи.
5. Нажми «Распознать речь» и дождись окончания. Если модель скачивается впервые, нужен интернет.
6. Проверь результат в «Речь стримера». Если слов нет, появится причина, а аудио сохранится для повторной попытки.

РЕЖИМ РУЛЕТКИ:
«Выбрать победителя»: победитель остаётся на колесе до следующей прокрутки, и виден в поле «Последний победитель».
«Выпавший выбывает»: выпавший исчезает после полной остановки.
