# Donathon Timer 0.9.4 Beta 3 — анализ сессий и гибкая рулетка

## Что нового

- **Анализ:** новая/недавно завершённая сессия появляется при входе в раздел. Список не перестраивается во время клика по раскрытому меню.
- **Анализ речи:** второй выбор сессии рядом с кнопкой распознавания. Верхний и нижний переключатели синхронизируются, а все четыре блока аналитики переключаются на выбранную сессию.
- **Рулетка:** переключение «Сразу победитель / Выпавший выбывает» рядом с настройкой скорости. Изменение применяется мгновенно, без повторной подготовки и сброса состава колеса.
- **Несколько победителей:** выбранный победитель удаляется из последующих прокрутов *после завершения анимации*, так что можно выбрать двух победителей, затем перейти к выбыванию среди остальных.
- Сохранено исправление DonationAlerts OAuth/local server из Beta 2.

## Загрузка

- `DonathonTimer-0.9.4-beta3-Setup.exe` — установщик Windows 10/11 x64.
- `DonathonTimer-0.9.4-beta3-Portable.zip` — версия без установки.
- `DonathonSpeech-0.9.4-beta3.zip` — опциональный модуль анализа речи, скачивается кнопкой из приложения.
- `SHA256SUMS.txt` — проверка файлов.

Устанавливать поверх Beta 2 с закрытым приложением. Пользовательские данные расположены в `%LOCALAPPDATA%\DonathonTimer` и не удаляются установщиком. Перед обновлением рекомендуется резервная копия `donathon.db`.

**Проверки:** Python compileall; модельное тестирование режимов рулетки; unittest для установщика компонента. GUI и OBS необходимо проверить на Windows.
