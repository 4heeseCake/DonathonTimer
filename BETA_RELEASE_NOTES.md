# Donathon Timer 0.9.4 Beta 4 — речь, рулетки и удобство

## Исправлено

- **Распознавание речи без стрима.** Twitch и OBS не нужны, но сохранение голоса нужно включить **до** запуска сессии. Внизу раздела «Анализ» отображается наличие записи, примерная длительность и размер.
- **Понятный ход распознавания.** Этап загрузки модели, обработка файлов, процент по обработанным фрагментам, прошедшее время, итог и явные причины ошибок. Первая загрузка модели может занять несколько минут; в этот период процент может долго стоять на 3 %.
- **Русские сообщения распознавателя.** Устранена зависимость от кодовой страницы консоли Windows: теперь технические сообщения передаются по ASCII-совместимому JSON и правильно показываются в GUI.
- **Нет распознанных слов?** Показывается ясное сообщение, исходное аудио не удаляется, чтобы можно было проверить микрофон и повторить попытку.
- **Облако речи.** Исправлена подсказка, которая ранее ошибочно упоминала Twitch-чат вместо микрофона.
- **Режим «Выбрать победителя».** Результат остаётся на колесе до следующего нажатия «Крутить»; перед следующим прокрутом прошлый победитель удаляется из выбора. В режиме «Выпавший выбывает» участник исчезает после остановки колеса. Под колесом сохраняется «Последний победитель».
- **Главная страница.** Две заметные, синхронизированные кнопки показать/скрыть таймер и рулетку (либо голосование) в OBS.
- **Поддержка.** В боковом меню появилась ссылка «Связь с техподдержкой», открывающая https://t.me/Cheese_Cake44.
- **Тексты.** Пересмотрены основные подсказки, инструкции по записи голоса, анализу и графикам; убраны некоторые технические и вводящие в заблуждение формулировки.

## Установка и данные

- `DonathonTimer-0.9.4-beta4-Setup.exe` — Windows 10/11 x64.
- `DonathonTimer-0.9.4-beta4-Portable.zip` — без установки.
- `DonathonSpeech-0.9.4-beta4.zip` — отдельный опциональный модуль речи.
- `SHA256SUMS.txt` — контрольные суммы.

Устанавливать поверх Beta 3 с закрытой программой. Пользовательские данные в `%LOCALAPPDATA%\DonathonTimer` не удаляются. Рекомендуется заранее скопировать `donathon.db` в безопасное место.

Это исходники для сборки, **не готовый Windows EXE**. Проверены синтаксис Python и автоматические тесты логики; проверку реального микрофона, OBS и Windows GUI необходимо провести на пользовательском компьютере.
