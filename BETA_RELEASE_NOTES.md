# Donathon Timer 0.9.4 Beta 5 — исправление распознавания речи

Исправлена ошибка `open() got an unexpected keyword argument 'metadata_errors'` при распознавании сохранённого голоса.

**Причина:** PyAV 19 несовместим с вызовом в faster-whisper 1.2.1. Для отдельного модуля речи закреплена проверенная версия PyAV 17.1.0, и в Windows-сборку добавлен обязательный тест чтения WAV через faster-whisper.

**Обновление:** установи Beta 5 поверх Beta 4 и нажми «Установить анализ речи» на вкладке «Анализ»: компонент Beta 4 будет заменён новой версией автоматически после подтверждения. Ранее записанная сессия сохранена, повторно говорить в микрофон не требуется. После установки компонента снова запусти распознавание той же сессии.

В выпуске:
- `DonathonTimer-0.9.4-beta5-Setup.exe` — Windows 10/11 x64;
- `DonathonTimer-0.9.4-beta5-Portable.zip` — без установки;
- `DonathonSpeech-0.9.4-beta5.zip` — новый исправленный модуль речи;
- `SHA256SUMS.txt` — контрольные суммы.

Twitch, DonationAlerts, рулетки и пользовательская база не менялись. Пользовательские данные остаются в `%LOCALAPPDATA%\DonathonTimer`.
