# Donathon Timer 0.9.4 Beta 2

Первая установочная бета для Windows 10/11 x64. Функции таймера, DonationAlerts, Twitch, OBS, сессий, аналитики, рулеток и голосований основаны на проверенной версии 0.9.3.2.

## Скачать

**Обычная установка:** `DonathonTimer-0.9.4-beta2-Setup.exe` — рекомендуемая версия. Один файл, ярлык, удаление через «Установленные приложения».

**Без установки:** `DonathonTimer-0.9.4-beta2-Portable.zip` — распакуй и запусти `DonathonTimer.exe` внутри папки. Не запускай EXE непосредственно из ZIP.

**Для анализа речи:** отдельный архив `DonathonSpeech-0.9.4-beta2.zip` загружается **самим приложением** при первом нажатии «Установить анализ речи» (его не нужно скачивать вручную). Для этого требуются доступ к GitHub Releases и интернет. Первая модель распознавания загружается дополнительно при первом анализе речи.

## Что проверить

- Авторизация DonationAlerts и поступление тестового доната
- Таймер и отображение в OBS Browser Source
- Подключение Twitch, чат-рулетка и голосование
- Прокрутка рулеток и финал на выбывание
- Работа Анализа и быстрые переходы между вкладками
- Установка модуля речи из интерфейса и распознавание после стрима
- Перезапуск программы и сохранение данных

**Важно:** это тестовая версия без коммерческой цифровой подписи. Windows может предупреждать о неизвестном издателе. Устанавливай только файл с официальной страницы релиза и при желании сверяй SHA-256 по `SHA256SUMS.txt`. Не отключай антивирус ради установки.

Настройки и история находятся в `%LOCALAPPDATA%\DonathonTimer`. Удаление программы их не очищает.
