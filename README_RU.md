# Donathon Timer 0.9.4 Beta 5

Первая Windows EXE-бета основана на проверенной версии 0.9.3.2. Присутствуют таймер донатофона, DonationAlerts, Twitch, OBS, оформление, сессии, история, аналитика, рулетки и голосования.

**Начни с файла `README_EXE_BETA_RU.md`.** В нём объясняется, как собрать и опубликовать обычный Windows-установщик `Setup.exe`, portable-архив и дополнительный модуль речи, который пользователь устанавливает из интерфейса.

- Система сборки: `buildtools/build-windows.ps1` (Windows + Python 3.12 + Inno Setup 6)
- Windows-установщик: `installer/DonathonTimer.iss`
- Автоматическая сборка и публикация: `.github/workflows/windows-beta-release.yml`
- Анализ речи: по кнопке, отдельный worker, модель загружается при первом распознавании.

**Это исходный проект и инструменты сборки, а не готовый Windows Setup.exe.** Windows-бинарники необходимо собрать на Windows. Пользовательские данные не входят в архив и не удаляются установщиком.

# Donathon Timer 0.9.0

Версия 0.9.0 добавляет последний крупный модуль перед EXE-beta: **«Развлечения»** — рулетки и голосования для Twitch-чата и DonationAlerts. Таймер, аналитика, сессии, DonationAlerts и Twitch остаются совместимыми с базой предыдущих версий.

## Новая вкладка «Развлечения»

В левой панели появилась отдельная вкладка `Развлечения` с четырьмя режимами.

### 1. Обычная рулетка

Стример вводит варианты по одному на строку и выбирает режим:

- первый выпавший — победитель;
- на выбывание — выпавший вариант удаляется, пока не останется последний.

Рулетку можно показать в OBS и крутить прямо из приложения.

### 2. Чат-рулетка

Стример задаёт ключевое слово, например `ХОЧУ`, и запускает сбор участников. Пользователь Twitch попадает в список только один раз, сколько бы сообщений он ни отправил.

Можно выбрать:

- сообщение должно быть ровно равно ключевому слову;
- достаточно, чтобы ключевое слово встретилось в сообщении.

После окончания сбора программа выбирает одного случайного победителя.

### 3. Донат-рулетка

После кнопки `Начать сбор` новые донаты с текстом автоматически становятся вариантами рулетки.

Пример:

```text
100 ₽   — ОФНИ СТРИМ
1000 ₽  — СМОТРИМ ФИЛЬМ
```

Шансы будут примерно:

```text
ОФНИ СТРИМ       9.1%
СМОТРИМ ФИЛЬМ   90.9%
```

Одинаковые варианты объединяются без учёта регистра и обычной пунктуации. Например `ОФНИ СТРИМ`, `офни стрим` и `Офни стрим!!!` суммируются в один сектор.

### 4. Голосование Twitch-чата

Стример задаёт вопрос и варианты, например:

```text
Во что играем дальше?

Cyberpunk
Гарри Поттер
CS2
```

Зритель может голосовать названием или номером:

```text
Cyberpunk
```

или

```text
1
```

Есть три режима подсчёта:

- один голос от одного пользователя;
- считать каждое сообщение;
- пользователь может изменить свой голос.

Результаты обновляются во время голосования.

## Единый OBS-оверлей

Для развлечений не нужен новый Browser Source. Используется тот же адрес:

```text
http://127.0.0.1:17321/overlay?v=0.9.0
```

Когда активна рулетка или голосование, интерактив появляется **над таймером**. В `Развлечениях` есть переключатель `Показывать основной таймер под интерактивом`, поэтому доступны три понятных сценария: только таймер, только интерактив или интерактив + таймер друг под другом.

Оформление интерактива подхватывает цветовые акценты выбранной темы таймера.

## DonationAlerts

1. Открой:
   https://www.donationalerts.com/application/clients
2. Создай OAuth-приложение.
3. Redirect URI:

```text
http://127.0.0.1:17321/oauth/callback
```

4. `App ID` — это Client ID для Donathon Timer.
5. В приложении: `Аккаунты` → `Ввести Client ID` → `Подключить DonationAlerts`.

Обычные DonationAlerts-алерты, их звуки, анимации и видео остаются независимым источником OBS и не изменяются Donathon Timer.

## Twitch

Twitch нужен для чата, онлайна, чат-рулетки и голосований.

1. Открой Twitch Developer Console:
   https://dev.twitch.tv/console/apps
2. Зарегистрируй приложение.
3. Если требуется Redirect URL, укажи:

```text
http://localhost:3000
```

4. Скопируй Client ID.
5. `Аккаунты` → `Ввести Twitch Client ID`.
6. Нажми `Подключить Twitch` и заверши авторизацию в браузере.

## Анализ речи

Компонент анализа речи можно установить из самого приложения:

`Анализ` → `Настройка анализа речи` → `Установить анализ речи`.

В будущей EXE-beta будет использована ленивая внутренняя установка: пользователю не придётся запускать BAT-файлы вручную.

## Хранилище и производительность

Тяжёлая аналитика по умолчанию хранится 20 дней. Автоматически можно очищать:

- сообщения Twitch-чата;
- замеры онлайна;
- расшифровки речи;
- временные записи микрофона.

Донаты и архив сессий автоматически не удаляются.

Файл базы:

```text
%LOCALAPPDATA%\DonathonTimer\donathon.db
```

Временное аудио:

```text
%LOCALAPPDATA%\DonathonTimer\recordings
```

## Что проверить в 0.9.0

1. Убедиться, что старый таймер, DonationAlerts, Twitch, сессии и Анализ не изменились.
2. `Развлечения` → обычная рулетка: проверить оба режима и несколько прокруток.
3. Чат-рулетка: запустить сбор по слову и написать это слово с нескольких Twitch-аккаунтов/пользователей.
4. Донат-рулетка: сделать несколько тестовых донатов с разными и повторяющимися сообщениями и проверить суммы/проценты.
5. Голосование: проверить голосование названием и номером, а также три режима подсчёта.
6. Открыть OBS-превью: голосование/рулетка должны появляться над обычным таймером в том же Browser Source.
7. Перезапустить приложение во время подготовленной рулетки/голосования — состояние должно восстановиться из базы профиля.
