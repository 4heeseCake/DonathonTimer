DONATHON TIMER 0.9.4 BETA 3 — ОБНОВЛЕНИЕ

1. В Анализе верхний список «Сессия» доступен всегда. Выбор меняет фильтр «Смотреть» на «Конкретная сессия», синхронизирует нижний список и пересчитывает графики.
2. Внизу, у распознавателя, есть второй список «Сессия» рядом с кнопкой «Распознать речь выбранной сессии». Списки связаны.
3. Список сессий обновляется при входе в Анализ, а не в момент попытки выбрать пункт.
4. В обычной рулетке режим сразу меняется справа от «Прокрут». Состав не сбрасывается.
5. В режиме «Сразу победитель» победители удаляются после завершения прокрутки, чтобы следующие победители были другими. В режиме на выбывание сохраняется финал с двумя участниками.

Как применить обновление к опубликованному репозиторию:
- Закрыть приложение.
- Содержимое ZIP обновления скопировать в корень DonathonTimer-GitHub с заменой совпадающих файлов (НЕ заменять папку .git).
- GitHub Desktop: Commit to main, затем Push origin.
- На GitHub Actions: Build and publish Windows beta → Run workflow → тег v0.9.4-beta3 → запустить.
- GitHub Releases: скачать новый Setup.exe и установить поверх Beta 2.
- Перед установкой желательно сохранить копию %LOCALAPPDATA%\DonathonTimer\donathon.db.

Проверка:
- Новая сессия доступна в Анализе после открытия раздела.
- Смена её сверху и снизу переключает аналитические блоки одновременно.
- Выбор комбобоксов производится ЛКМ; обычное вращение колеса мыши значения не меняет.
- 5 вариантов → дважды «Сразу победитель» → остаются 3 → «Выпавший выбывает» → оставшиеся 3 игрока без новой подготовки.
- DonationAlerts и OBS после обновления работают как раньше.
